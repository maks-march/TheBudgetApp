# Бюджет — Android-приложение (Kotlin, MVP)

Нативное Android-приложение личного бюджета по логике Google-таблицы.
Минимальный рабочий скоуп, без эмодзи, тёмная тема Material 3.

## Скоуп MVP

- **Экран «Сегодня»**: дельта (свободные деньги накопительно), конверты месяца
  (доступно / потрачено / перенос далее), бюджет на день, последние операции.
- **Экран «Бюджет»**: конвертный бюджет по категориям (план-факт), тап по категории —
  изменение плана месяца.
- **Добавление операции** (кнопка «+»): сумма → тип (расход/доход) → категория → дата → заметка.
  Тап по операции в списке — редактирование/удаление.
- **Навигация по месяцам** со стрелок у заголовка.

### Ключевая логика (конверты с переносом)

```
available(m) = plan(m) + carryIn(m)      // доступно = план + перенос с прошлого месяца
left(m)      = available(m) − spent(m)   // остаток; уходит в следующий месяц (со знаком)
carryIn(m)   = left(m−1)                 // перерасход уменьшает следующий месяц
delta(m)     = income(m) − expense(m)    // накопительно за год с переносом
```

Планы по умолчанию (аренда 4000, продукты 10000, кофе 1000 и т.д.) засеиваются
при первом запуске на месяцы с текущего до конца года.

## Требования

- Android Studio Koala (2024.1.1) или новее
- JDK 17 (входит в поставку Android Studio)
- minSdk 26 (Android 8.0), target/compile SDK 34

## Сборка

1. Открыть папку `BudgetApp` в Android Studio: **File → Open**.
2. Дождаться Gradle Sync (Gradle 8.9 скачается сам по `gradle-wrapper.properties`;
   если Studio спросит про недостающий wrapper — согласиться на исправление,
   либо выполнить в терминале `gradle wrapper --gradle-version 8.9`).
3. **Run ▶** на эмуляторе или устройстве.

CLI: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

## Стек

| Слой | Решение |
|---|---|
| UI | Jetpack Compose + Material 3 (тёмная тема, dynamic color не используется) |
| Архитектура | MVVM: `AppViewModel` + `StateFlow<AppState>` |
| БД | Room (таблицы `transactions`, `plans`), KSP |
| Расчёты | `BudgetEngine` — чистый Kotlin без Android-зависимостей (тестируется юнит-тестами) |

## Структура

```
app/src/main/java/ru/budget/app/
├── MainActivity.kt            — точка входа
├── data/
│   ├── Model.kt               — категории (справочник) и группы потоков
│   └── Db.kt                  — Room: сущности, DAO, база
├── domain/
│   └── BudgetEngine.kt        — конверты, переносы, дельта, итоги месяца
└── ui/
    ├── Theme.kt               — цвета и тема
    ├── Common.kt              — формат денег, даты, GroupDot
    ├── AppViewModel.kt        — состояние + действия
    ├── AppRoot.kt             — scaffold, навигация, переключатель месяцев
    ├── TodayScreen.kt         — дашборд
    ├── BudgetScreen.kt        — план-факт + диалог плана
    └── AddSheet.kt            — шторка добавления/редактирования
```

## Дорожная карта (не вошло в MVP)

1. Накопления: счета, переносы «в накопления», цели 10/20% от дохода.
2. Калькулятор распределения дохода (50/30/20 и свои проценты).
3. Кастомные категории (сейчас — фиксированный справочник).
4. Копирование плана месяца на весь год.
5. Виджет быстрого ввода, напоминания о лимитах.
6. Экспорт/импорт (CSV/JSON), синхронизация с Google Sheets.
7. Юнит-тесты `BudgetEngine` (формулы переносов — ключевой сценарий).
