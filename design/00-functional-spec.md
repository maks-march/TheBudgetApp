# BudgetApp — реестр функционала и план макетов

Документ-основа: сначала функционал, потом экраны, потом верстки.
Статусы: **[MVP]** — уже реализовано в коде, **[новое]** — предстоит.

Приоритеты:
- **P0 — ядро**: без этого приложение не работает (первая версия)
- **P1 — важно**: заметно улучшает жизнь (вторая итерация)
- **P2 — потом**: приятно иметь (копилка идей)

## Маппинг «функции → экраны»

| Экран | Закрывает | Приоритет экрана |
|-------|-----------|------------------|
| **С1. Траты** — главный экран: круговая диаграмма расходов по категориям, быстрые траты, лента по дням | A4, A8 + диаграмма | P0 |
| **С2. План-факт** — конверты с переносом остатков | V1–V8 | P0 |
| **С3. Добавление** — шторка (трата / доход / новая быстрая) | A1–A5 | P0 |
| **С4. Доходы** — список доходов месяца, активный/пассивный | A2, G3, G4 | P0 |
| **С5. История** — журнал операций | A6, A7, A8, Z2 | P1 |
| **С6. Аналитика** — графики | J1–J4 | P1 |
| **С7. Настройки** | Z1, Z3, I1, I2 (категории — только из шторки С3) | P1 |
| **Виджет** | A4 | P2 |

Навигация (решено, ревизия 2 — по итогам макета С1):
- Внизу три вкладки: **Траты (главная) · Доходы · План-факт**
- FAB «+» — над навигацией справа, не в центре панели
- История — ссылкой под лентой трат; Аналитика — из План-факта (итерация 2)
- Настройки — иконка в шапке

## План итераций макетов

1. **Итерация 1 (P0):** С1 Траты → С3 Добавление → С2 План-факт → С4 Доходы — ТЕКУЩАЯ (С1, С3 согласованы; С4 и С7 (досрочно) на согласовании; остался С2)
2. **Итерация 2 (P1):** С4 История → С6 Аналитика → С7 Настройки
3. **Итерация 3 (P2):** С5 Накопления + калькулятор, виджет, напоминания, PIN

Решения по составу (зафиксировано):
- накопления перенесены в P2, первая версия без них;
- рекуррентные платежи (A9) — отклонены, ввод только ручной;
- ревизия 2 (макет С1): дельта убрана из интерфейса (G2 отложена); главный экран —
  «Траты» с круговой диаграммой по категориям; «повтор траты» заменён на управляемые
  «Быстрые траты» (A4); нижняя навигация — Траты / Доходы / План-факт, FAB справа над панелью;
- ревизия 2 (макет С3): заметка убрана из ввода (A5 сужена); свои категории подняты в P0 (B2):
  «＋» в шторке, зажатие чипа — удаление/скрытие; дата выбирается календарём.

Каждая итерация: согласовываем состав → верстка экрана → правки → перенос в Compose.
