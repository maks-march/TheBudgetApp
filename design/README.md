# Design-папка BudgetApp

Порядок работы: **функционал → экраны → верстки → Compose**.

| Файл | Что это |
|---|---|
| `00-functional-spec.md` | реестр всего функционала + приоритеты + маппинг на экраны |
| `C1-today.html` | главный экран «Траты» — **согласован**, рев. 4 |
| `C3-add.html` | шторка добавления — **согласована**, рев. 2 |
| `C4-income.html` | экран «Доходы» — на согласовании |
| `C7-settings.html` | «Настройки» — досрочно из итерации 2, на согласовании |

Верстки финальных экранов появляются здесь по итерациям, после согласования
состава в `00-functional-spec.md`:

- Итерация 1 (P0): Добавление → Сегодня → Бюджет
- Итерация 2 (P1): История → Аналитика → Настройки
- Итерация 3 (P1): Накопления + калькулятор
- Итерация 4 (P2): виджет, напоминания

Палитра = `app/src/main/java/ru/budget/app/ui/Theme.kt`.
